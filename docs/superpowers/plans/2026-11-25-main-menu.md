# Main Menu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the flat scrolling menu with a title screen and one sub-screen per decision (lists, run setup, Settings, Controls, What's new, About), plus Continue and a Settings level in the pause sheet.

**Architecture:** The screen graph, catalogue and option fields are plain data, and navigation is a pure function from stack and event to stack, all under `src/app/menu/`. A DOM layer renders one screen kind at a time inside `.app-screen` and maps the stack to the app's single history entry (`enter`/`leave` in `app.ts`). The menu's static import graph stays free of three.js; drive and replay stay behind `import()`.

**Tech Stack:** TypeScript (strict, `exactOptionalPropertyTypes`), plain DOM, Vite, Vitest (node environment), Playwright, pnpm.

**Spec:** `docs/superpowers/specs/2026-11-25-main-menu-design.md` (PR #474). Read it with this plan. Where this plan settles one of the spec's "Left to the builder" points, the plan is binding.

## Review Focus

1. Double activation (double click or tap, Enter followed by a click) on Start or Continue starts exactly one drive. Tests: Task 2.5 (`a double click on Start …`), Task 3.2 (`a double click on Continue starts one drive`).
2. A drive chunk that fails to load while Start is busy ends in the load-failed notice. Its Back lands on the title with no stale history entry, and Retry still works. Test: Task 2.5 (`retry.spec.ts`).
3. Stored settings from an older build, or edited by hand (no `lastEntry`, an unknown id, a wrong kind or role), never crash the title. Continue falls back to the last run's entry or hides. Tests: Task 3.1.
4. Tab on the pause sheet's Settings level (radios, not only buttons) stays inside the dialog, and driving keys never reach the paused run. Test: Task 6.1.
5. A language switch in Settings re-renders in place and keeps focus on the chosen value. Back then shows the title in the new language. Test: Task 2.6.
